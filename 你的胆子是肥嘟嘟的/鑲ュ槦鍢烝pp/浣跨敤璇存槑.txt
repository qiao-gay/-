你的胆子是肥嘟嘟的 · 萌系三消 App
====================================

【怎么打开】
直接双击 index.html 即可用浏览器玩（支持 Chrome / Edge / Safari / Firefox）。

【怎么装到桌面】
1. 先打开 install.html 查看各设备的安装引导。
2. iPhone：Safari → 分享 → 添加到主屏幕。
3. 安卓：Chrome → 菜单 → 安装应用。
4. 电脑：Chrome / Edge 地址栏右侧「安装」图标。

【支持的功能】
- 简单 / 中等 / 困难 三档难度
- 5 个关卡，关卡插画随难度切换
- 4连/5连生成特殊宝石，连锁反应
- 过关 / 失败弹窗配袋鼠表情包
- 13 种合成音效 + 静音开关
- 浅色 / 深色 / 跟随系统 三档主题
- 可安装到桌面，断网也能玩

【注意】
首次打开需要联网加载一次，之后资源会缓存在本机，离线可玩。
最高分、解锁关卡、主题偏好均保存在本机浏览器，不会上传。
