🦘 你的胆子是肥嘟嘟的

萌系三消 · 可安装到手机 / 电脑桌面

📱 手机端（推荐）

iPhone / iPad：用 Safari 打开本页面 → 点底部中间的 分享按钮 → 选 「添加到主屏幕」 → 点右上角「添加」。之后就像 App 一样从桌面图标启动。
安卓：用 Chrome 打开本页面 → 点右上角 ⋮ 菜单 → 选 「安装应用」 或「添加到主屏幕」。也可等页面底部自动弹出安装提示。

💻 电脑端

Chrome / Edge：打开页面后，地址栏右侧会出现 「安装」图标（向下箭头）→ 点击即可装到桌面；也可按 F12 后忽略。
没有安装图标时，点浏览器右上角 ⋮ → 投射/保存/更多工具 → 安装「你的胆子是肥嘟嘟的」。

🎮 离线也能玩

首次打开后会自动缓存所有资源，之后断网也能玩，进度与最高分保存在本机。
💡 已装到桌面？点右上角「开始游戏」直接进入。本页只是安装引导，平时不需要打开。
